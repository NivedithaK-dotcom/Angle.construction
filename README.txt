MYSURU CONSTRUCTION WEBSITE
===========================

Files:
- index.html: website structure and content
- style.css: layout, colors, responsive design and animations
- script.js: mobile navigation, scroll progress, reveal animations, count-up and WhatsApp form

HOW TO PREVIEW
1. Keep all three files in the same folder.
2. Double-click index.html to open it in your browser.

HOW TO HOST FREE
1. Create a GitHub account and a new public repository.
2. Upload index.html, style.css, and script.js.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. GitHub will provide your public website URL.

BEFORE PUBLISHING
- The construction photos are illustrative Unsplash images; replace them with your own real project photos.
- Check the company/customer name spelling and get permission to display Masson Polymer Industries as a customer.
- The form opens WhatsApp to +91 95389 40672. It does not save submissions to a database.
